This folder already contains the SDK's API-only jar:

    re-academycraft-forge-1.20.1-1.5.0-api.jar

That is enough to BUILD the add-on (locally or on GitHub).

To RUN the add-on in Minecraft you also need the normal Re:AcademyCraft 1.5.0 mod jar from CurseForge, but it goes in the
mods folder of your Minecraft instance, not here. (If you do put it here as re-academycraft-forge-1.20.1-1.5.0.jar,
the build will compile against it instead.)
